DeckWerk features

Every feature DeckWerk has, and where to find it in the app.

Each entry says what the feature does and where it is. Features go by the names Keynote and PowerPoint use, and search finds those names too. Paths use the labels the app shows: Props›Typography›Role is the Role field in the Typography section of the Props tab. Shortcuts are written for macOS; on Windows and Linux use Ctrl for Cmd.

Where an agent writes the feature in a slide's HTML, In HTML shows the markup. Entries marked (new) are on a branch and not in a release yet.

No features match.

Slides and layout

Slide navigator

The slide thumbnails down the left of the window. Drag a thumbnail to move the slide. With the thumbnails focused, Return adds a slide, Delete removes one and the arrow keys move between slides.

Where: Left column›+ Slide, Duplicate, Hide, Delete, or right-click a thumbnail

Skip a slide

A skipped slide stays in the deck and can still be edited. Presenting and the web export leave it out. Several skipped slides in a row fold into one "N hidden" row in the navigator.

Where: Slide navigator›Hide, or right-click a thumbnail›Hide slide

Slide layouts

A layout places the title and body boxes of a slide. There are three: Freeform, Title + body and Title slide.

Where: Props tab (nothing selected)›Layout›Preset, or right-click a thumbnail›Layout

In HTML
<section class="slide" data-layout="standard">
  <h1 class="role-title">Results</h1>
</section>

Master slides

Change where a layout puts its boxes, for every slide that uses it. The layout editor has Text, Shape, Duplicate and Delete tools.

Where: Design tab›Layouts›Edit layouts…, or Props tab›Layout›Preset›Edit layouts…

Slide background

Each slide can have its own background colour. A full-bleed background picture is set in HTML or by an agent; the editor shows it but has no control for it.

Where: Props tab (nothing selected)›Layout›Background

In HTML
<section class="slide" style="background-color:#0f172a">
<section class="slide" style="background-image:url('assets/photo.jpg')">

Themes

A theme is a set of fonts for title, body and caption, a colour palette, and background and text colours. DeckWerk ships 12 themes, each in a light and a dark version. Choosing a theme moves nothing on a slide.

Where: Design tab›Current theme›click the theme card

Edit a theme

Change the typefaces, the type sizes and line spacing for Title, Body and Caption, the four main colours and the palette swatches.

Where: Design tab›Default›Edit…

Apply a theme

Restyle slides that already exist: the whole deck, the selected slides or the selected objects. You choose which text styles and which properties (typography, type sizes, colour) to take.

Where: Design tab›Apply theme›Apply to

Alignment guides

While you drag, objects snap to the slide edges and centre, to other objects' edges and centres, to equal spacing and to matching sizes. Hold Cmd (Ctrl on Windows and Linux) to drag without snapping.

Where: On the slide, while moving or resizing an object

Rulers

Rulers along the top and left of the slide show the selection's extent and the pointer position in slide pixels.

Where: Zoom controls at the bottom of the slide›ruler button, or Cmd+R

Zoom

Zoom the slide in and out, or fit it to the window.

Where: Zoom controls›Zoom out, percentage, Zoom in, Re-center slide, or Cmd+=, Cmd+- and Cmd+0 (fit)

Object list

Every object on the slide, front to back, including ones covered by others. Click a row to select the object. Drag rows to restack.

Where: Layers button at the top of the column left of the slide›Objects

Align and distribute

Align several objects by their edges or centres, spread them evenly, or match their width and height to the first one selected.

Where: Select several objects›Props tab›Align

Bring to front, send to back

Move an object in front of or behind others.

Where: Right-click›Bring to front, Bring forward, Send backward, Send to back, or Props tab›Geometry›Layer›Arrange, or ] and [ (with Shift for front and back)

Presenter notes

Notes for each slide, shown on the presenter display. They are Markdown and live in notes.md in the deck folder, one section per slide.

Where: Notes button at the bottom left of the slide

Edit history

Every edit, yours, a collaborator's or an agent's, as a list you can go back to. Going back is an edit too, so it can be undone.

Where: History tab, or Cmd+Z and Cmd+Shift+Z

Text

Text boxes

Text adds a box that grows with what you type. Double-click a box, or right-click > Edit text, to change it.

Where: Toolbar›Text

In HTML
<p class="role-body">Body text with <b>bold</b> and <i>italic</i>.</p>

Text styles

A text style (Title, Body or Caption) takes its font, size and colour from the theme, so a theme change restyles the text. A "+" after the style means the box has its own changes; Reset to theme removes them.

Where: Props tab›Typography›Role, and Reset to theme below it

In HTML
<h1 class="role-title">A title</h1>
<p class="role-caption">Figure: First Author et al.</p>

Font, size and weight

Pick a font (theme fonts first, then installed fonts), a size in pixels and a weight from 1 to 1000. When the text has been shrunk to fit, the size field says "Fitted to N px".

Where: Props tab›Typography›Font family, Font size, Font weight

Bold, italic, underline, strikethrough

Style selected characters, or the whole box when it is selected but not being edited. Superscript and subscript work on selected characters.

Where: Props tab›Typography›Style, or Cmd+B, Cmd+I, Cmd+U, Cmd+Shift+X (strikethrough), Cmd+Shift+= (superscript), Cmd+Shift+- (subscript)

In HTML
<p>Error <s>4.1%</s> 2.7%, x<sup>2</sup></p>

Text colour

Colour the whole box or selected characters. The clear option goes back to the theme's text colour.

Where: Props tab›Typography›Colour

Text alignment

Horizontal alignment (left, centre, right, justify) and where the text sits in its box (top, middle, bottom).

Where: Props tab›Paragraph›Align, Vertical

In HTML
<p class="role-body" style="text-align:center" data-valign="bottom">…</p>

Line and paragraph spacing

Line spacing is a multiple of the font size. Paragraph spacing is the gap in pixels between paragraphs and between list items.

Where: Props tab›Paragraph›Line spacing, Paragraph spacing

In HTML
<ul data-paragraph-spacing="12" style="line-height:1.2">…</ul>

Bullets and numbering

Bulleted and numbered lists are real lists, so an animation can reveal them one item at a time. The bullets can have their own colour.

Where: Props tab›Paragraph›List›No list, Bulleted list, Numbered list, then Marker colour

In HTML
<ul>
  <li>First point</li>
  <li>Second point</li>
</ul>

Bullet styles

Bullets: disc, circle, square, dash, triangle, arrow, check. Numbers: 1. and 1) numbers, lower and capital letters, lower and capital Roman numerals.

Where: Props tab›Paragraph›Bullet (turn on a list first)

In HTML
<ul data-bullet="check">…</ul>
<ol data-bullet="lower-roman">…</ol>

Indent

Move a list item or a paragraph one level in or out. A list item moves under the item above it.

Where: Props tab›Paragraph›Indent, or Tab and Shift+Tab in a list, or Cmd+] and Cmd+[

In HTML
<p data-indent="1">An indented paragraph</p>

Links

Paste an http(s) or www. address while text is selected to link that text. Typing an address followed by Space or Return links the address.

Where: While editing text›select text›paste a URL

In HTML
<a href="https://example.org/paper">Paper</a>

Shrink text to fit

Shrinks text so it stays inside its box. Size box to text makes the box hug its text instead. With automatic line breaks off, a long line either shrinks or is condensed sideways.

Where: Props tab›Paragraph›Auto-fit text to box, Size box to text, Disable automatic line breaks›Compress by

In HTML
<h1 class="role-title" data-autofit="true">A long title</h1>
<p data-nowrap data-fit-mode="condense">One line, never wrapped</p>

Text box fill, border and shadow

Give a text box a fill, a border and rounded corners, and a shadow on the box or on the letters.

Where: Props tab›Box›Fill, Border, Width, Radius, and Props tab›Text shadow›Drop shadow

Tables

Insert a table up to 8 rows by 10 columns. Cells take fills, text colour and borders, and columns can be added and removed.

Where: Toolbar›Table›pick a size, then Props tab›Table

In HTML
<table>
  <tr><th>Method</th><th>Score</th></tr>
  <tr><td>Step 1</td><td>0.81</td></tr>
</table>

Spelling and grammar

Spelling and grammar are checked on your computer while you type. Right-click a marked word for suggestions, Add to dictionary or Ignore.

Where: While editing text›right-click›Check spelling and grammar

Shapes and drawing

Shapes

Rectangles, ellipses, trapezoids, parallelograms, four-sided shapes, lines and arrows. Change the kind, fill, outline, width and corner radius after inserting.

Where: Toolbar›Shape, then Props tab›Style

In HTML
<div data-element="shape" data-shape="rect" data-stroke="#2563eb"
     data-stroke-width="4" data-radius="16" style="width:460px;height:240px"></div>

Arrowheads

Put a head on either end of a line or arrow, or both. Head size is in pixels; Auto scales it with the line width.

Where: Props tab›Style›Head at end, Head at start, Head size

In HTML
data-shape="arrow" data-arrow-start="true" data-arrow-end="true" data-arrow-size="24"

Curved arrows

An arrow with one bend handle. Drag the round handle to bend it; the head turns with the end of the curve.

Where: Toolbar›Shape›Curved arrow, or Props tab›Style›Curved on an arrow

In HTML
data-shape="arrow" data-arrow-end="true" data-control="950,260"

Curly braces

A brace laid out like a line. Its depth sets how far the point sticks out.

Where: Toolbar›Shape›Curly brace, then Props tab›Style›Depth, or drag the brace's tip

In HTML
<div data-element="shape" data-shape="brace" data-brace-depth="40"></div>

Draw with Pen

Draw a free-form shape. Click for corners, drag for curves. Click the first point to close and fill the shape, or press Return to finish an open line. Backspace removes the last point.

Where: Toolbar›Pen, or Toolbar›Shape›Draw with Pen

In HTML
<div data-element="shape" data-shape="path" data-path="M 0 150 C 0 -50 300 -50 300 150 Z"
     data-path-size="300,150" style="width:300px;height:150px"></div>

Line styles

A drawn line can be Pen (even), Brush (swells and tapers), Pencil (thin and grainy) or Marker (a wide see-through highlighter).

Where: Toolbar›Pen›style menu before drawing, or Props tab›Style›Stroke style after

In HTML
data-shape="path" data-stroke-style="brush"

Edit points

Drag the points of a drawn shape to change it.

Where: Double-click a drawn shape, or right-click›Edit points, or Props tab›Style›Edit points

Shadows

A drop shadow with colour, blur, angle and distance, or a curved shadow where the object lifts at its bottom corners. The shadow follows the shape's own outline.

Where: Props tab›Shadow›Drop shadow›Style: Drop or Curved

In HTML
style="filter: drop-shadow(0px 8px 24px rgba(0, 0, 0, 0.3))"

Gradient fills

Fill a shape with a linear or radial gradient from its fill colour to a second colour. A linear gradient has an angle.

Where: Props tab›Style›Fill style›Linear gradient or Radial gradient, then To and Angle

In HTML
data-fill="#f59e0b" data-fill-to="#dc2626" data-fill-angle="270" data-fill-gradient="linear"

Flip and rotate

Rotate any object with the dial or an exact angle (Shift snaps to 15°). Flip mirrors it along the slide's own axes; text stays editable.

Where: Props tab›Geometry›Rotate, Angle, Flip

In HTML
style="transform: rotate(30deg) scaleX(-1)"

Position, size and opacity

Exact position and size in slide pixels, and opacity from 0 to 100%. Arrow keys nudge by 1 pixel, Shift+arrow by 10. Alt-drag makes a copy.

Where: Props tab›Geometry›Position, Size, Opacity

Colours and eyedropper

Every colour field opens the same picker, with the theme's swatches and an eyedropper that picks a colour from anywhere on screen.

Where: Any colour field›Pick a colour from the screen

Images and video

Images

Drag or paste images onto a slide: PNG, JPEG, GIF, WebP, SVG, AVIF, PDF, HEIC, TIFF and BMP. PDFs and SVGs stay vector.

Where: Drag a file onto the slide, or paste

In HTML
<img src="assets/figure.png" alt="Results" style="width:800px;height:500px;object-fit:contain">

Video

Drag or paste MP4, MOV, M4V, WebM, MKV or AVI. A slide video plays by itself, loops and is muted unless you change it. Formats a browser cannot play are converted on import.

Where: Drag a file onto the slide, then Props tab›Playback›Autoplay, Loop, Mute, Controls, Play preview

In HTML
<video src="assets/clip.mp4" autoplay loop muted></video>

Crop

Move and scale the picture inside its box. The file on disk is not changed, and the crop can be changed or reset later. Works the same on video.

Where: Double-click an image, or Props tab›Mask›Edit mask, or right-click›Edit mask (crop)

In HTML
<img src="assets/figure.png" data-crop="-300,-200,1200,800">

Circle crop and rounded corners

Crop an image or video to a circle, or round its corners.

Where: Props tab›Mask›Circular mask, Corner radius, or right-click›Circular mask

In HTML
<img src="assets/headshot.jpg" data-mask-shape="circle" style="width:440px;height:440px">

Picture borders and effects

A border with colour and width, and effects that stack in order: blur, posterize, greyscale and Gaussian noise. Reorder them with the arrows.

Where: Props tab›Border›Color, Width, and Props tab›Effects›+ Add effect

In HTML
data-border-width="6" data-border-color="#111111" data-border-radius="12"

Trim video

Play only part of a clip. Looping repeats the trimmed part. The file on disk is not changed.

Where: Props tab›Trim›Range, and Reset trim

In HTML
<video src="assets/clip.mp4" data-trim="12,20"></video>

Play videos together

Videos played together start, pause and loop from one clock while presenting, each from its own trim start.

Where: Select several videos›Props tab›Playback›Play in sync, and Unsync on one of them

In HTML
<video src="assets/a.mp4" data-sync-group="pair"></video>
<video src="assets/b.mp4" data-sync-group="pair"></video>

Before and after comparison

Two pictures or videos stacked in one box with a divider between them: the upper one shows left of the divider, the lower one right of it. Videos compared this way also play together. The presenter can drag the divider while presenting.

Where: Select two images or two videos›Props tab›Compare›Arrange as wipe, then Wipe›Divider, Turn off wipe

In HTML
<video src="assets/before.mp4" data-sync-group="w"></video>
<video src="assets/after.mp4" data-sync-group="w" data-compare="wipe" data-wipe="0.5"></video>

Compare button (new)

Selecting two images or two videos shows a small Wipe button under them on the slide. It does the same as Arrange as wipe. The same item is in the right-click menu.

Where: Select two images or two videos›Wipe

Comparison length (new)

When the two clips of a comparison differ in length: Shortest ends with the shorter clip, Hold last runs to the longer clip and freezes the shorter one on its last frame, Black runs to the longer clip and blacks out the shorter one.

Where: Select a compared pair of videos›Length›Shortest, Hold last, Black, or Props tab›Wipe›Length

In HTML
<video src="assets/after.mp4" data-sync-group="w" data-sync-length="hold"></video>

Video controls while presenting

While presenting, hovering a video shows a bar along its bottom: play and pause, a scrubber over the trimmed part, the time and a speed slider. For videos played together it controls them all. It never shows in PDFs or thumbnails.

Where: While presenting, move the pointer over a video

Video speed

Speed up or slow down every video on the current slide while presenting: 0.25, 0.5, 1, 1.5, 2, 4 or 8 times. Leaving the slide returns to normal speed.

Where: While presenting,›or ] (faster), < or [ (slower), = (normal), or the speed slider in the video controls

Media browser

Every image, video, web page and 3D model in the deck, with the slides that use it. Search by file name, filter by type, add a file to the current slide, and find and remove unused files.

Where: Media tab›Search, Type, On this slide, +, Unused files›Rescan

Re-encode or paint

Edit w/ ffmpeg re-encodes a video into a new file. Rasterize & paint paints over an image as a new PNG. The original is kept in both cases. Download original saves the source file.

Where: Props tab›Advanced›Edit w/ ffmpeg… or Rasterize & paint…, or right-click›Download original…

Animations

The app calls them builds, in the Build tab (Keynote: Animate; PowerPoint: Animations).

Add an animation

An animation shows, hides or moves an object during a slide. Each step runs on a click, with the step before it, after it, or when a video ends, with an optional delay. Objects without an animation are on screen from the start.

Where: Build tab›select an object›Add animation, then the trigger (click, after, with, media) and the action menu

In HTML
<img src="assets/a.png" data-build="click">
<img src="assets/b.png" data-build="afterPrev+500">

Animation order

While the Build tab is open, each object shows a numbered badge for its steps. Drag a step's handle to reorder it; drop it on the middle of another step to play both together.

Where: Build tab›Build steps›drag the handle

Appear, dissolve and blur

Appear and disappear are instant. Dissolve fades in or out. Blur comes into focus, or goes out of it.

Where: Build tab›action menu›appear, dissolve in, blur in, disappear, dissolve out, blur out

In HTML
data-build="click" data-build-effect="dissolve" data-build-duration="500"

Line Draw

A line or arrow grows from its start, head first. A box, ellipse or drawn shape is traced along its outline and its fill fades in after. Works on every line style.

Where: Build tab›action menu›line draw (shapes only)

In HTML
data-build="click" data-build-effect="draw"

Pop

The object grows in from smaller, overshoots a little and settles.

Where: Build tab›action menu›pop in, then from and overshoot

In HTML
data-build="click" data-build-effect="pop" data-build-pop-from="0.6" data-build-pop-peak="1.06"

Keyboard

Text types in a character at a time behind a moving caret.

Where: Build tab›action menu›keyboard (text only)

In HTML
data-build="afterPrev" data-build-effect="keyboard" data-build-duration="1500"

By paragraph

Reveal a text box one paragraph or list item at a time, from one animation step.

Where: Build tab›Add animation by paragraph, or action menu›appear by paragraph

Start and stop video

Start or pause a video as an animation step. The media trigger starts the next step when a video ends.

Where: Build tab›action menu›play, pause, and the media trigger

Actions: pulse, jiggle and pop

Movements that end where they began. Pulse enlarges the object, holds, and settles back; pulse (lift) also casts a shadow and rises above its neighbours. Jiggle wobbles side to side. Pop eases up and back down. Damping (0 to 1) sets how soft the movement is.

Where: Build tab›Add pulse, then action menu›pulse, pulse (lift), jiggle, pop, and scale, damping

In HTML
data-pulse="click" data-pulse-scale="1.6" data-pulse-lift="true"
data-jiggle="click"  data-pop="click" data-pop-scale="1.3"

Preview animations

Preview plays the selected object's animation in place. Play slide runs every step of the slide in turn. The button reads Stop while playing; Esc also stops.

Where: Build tab›▶ Preview, ▶▶ Play slide

Transitions

Morph

Animate from one slide to the next (Keynote calls it Magic Move): paired objects move, resize and change colour, and everything else fades. Enable and Auto-Pair pairs what it can match. Duration is per slide; the motion curve is for the whole deck.

Where: Select the earlier slide›Props tab›Morph›Enable and Auto-Pair, Duration, Motion curve

In HTML
<h1 data-morph="diagram">…</h1>
<section class="slide" data-morph-from-previous="true" data-morph-duration="1000">

Pair objects by hand

Choose an object on the source slide, then its partner on the target slide. Auto-pair and Clear pairs reset the pairing.

Where: Props tab›Morph›Open Morph editor…

Morph across several slides

Turn on Morph and auto-pair for every slide in a selection at once.

Where: Select several slides in the navigator›Props tab›Enable Morph & Auto-Pair

Equation Morph

When two paired text boxes hold different equations, each shared symbol travels to its new place and size, and symbols only one side has fade in or out. It happens on its own for any paired maths.

Where: Pair two equations with Morph

In HTML
<p data-morph="eq">$$a^2 + b^2 = c^2$$</p>

Equations

LaTeX equations

Write maths in any text box between dollar signs: $…$ inline, $$…$$ on its own line. It renders as you type. Write a literal dollar as \$.

Where: Any text box›type $…$

In HTML
<p>The mean $\bar{x}$ and $$\int_0^1 x^2\,dx = \frac{1}{3}$$</p>

Build an equation term by term

Mark terms in the TeX with \step{1}{…}, \step{2}{…}, and the equation appears one term per click. Terms not yet shown keep their place, so nothing moves.

Where: Build tab›Add term build›action build terms

In HTML
<p data-term-build="click">$$y = \step{1}{a x^2} + \step{2}{b x} + \step{3}{c}$$</p>

Colour terms

Paint marked terms a colour, one step at a time, and they stay painted.

Where: Build tab›Add term build›action color terms›Highlight

In HTML
data-term-build="click" data-term-effect="color" data-term-color="#0588ff"

Pulse a term

Pulse, jiggle or pop one marked term to point at it. Without a term the whole object moves.

Where: Build tab›Add pulse›term

In HTML
data-pulse="click" data-pulse-term="2"

Code blocks

Code blocks

Source code highlighted in a choice of colour schemes, offline. Whitespace is kept exactly. The Deck scheme takes its colours from the theme.

Where: Toolbar›Code, then Props tab›Code›Source, Language, and Appearance›Colour scheme, Size, Line numbers

In HTML
<pre data-element="code" data-language="python" data-scheme="deck" data-line-numbers="true">
<code>def f(x):
    return x * 2</code></pre>

Reveal code line by line

Reveal or highlight lines step by step. Steps are separated by ;: 1-3 reveals lines 1 to 3, highlight:5 dims every other line, highlight:all ends the highlight.

Where: Build tab›Add line build›lines

In HTML
<pre data-element="code" data-build-lines="1-3; 4-6; highlight:5">…</pre>

Charts

Charts

Bar, stacked bar, line, area and scatter charts drawn from CSV kept in the chart. They use the theme's fonts and colours and stay editable. Cells may carry units like 12% or 3.2 ms.

Where: Toolbar›Chart›Bar, Stacked bar, Line, Area, Scatter or From CSV file…, or drop a CSV file on the slide, then Props tab›Type, Data, Axes

In HTML
<figure data-element="chart" data-kind="bar" data-x="method" style="width:1200px;height:640px">
  <script type="text/csv">method,score
Step 1,0.81
Baseline,0.72</script>
</figure>

Chart colours and labels

Palettes: Deck, Tableau 10, Okabe-Ito (colour-blind safe), Viridis, Grayscale + accent, or your own from a hex list or a coolors.co link. Legend position, value labels on bars and text size are set here too.

Where: Props tab›Style›Palette, Import palette, Highlight, Legend, Value labels on bars, Text size

In HTML
data-palette="okabe-ito" data-legend="top" data-value-labels="true"

Animate a chart

Reveal a chart one series or one group of bars per click.

Where: Build tab›action menu›appear by series, appear by category

In HTML
data-build="click" data-build-effect="bySeries"

Paper cards

Paper cards

A related-work card: the top of the paper's first page (or a screenshot of its project page) with a shadow, the title in bold and an "Authors, Venue Year" line. It is three ordinary objects you can move and restyle.

Where: Toolbar›Paper›arXiv, DOI or web address, or Choose PDF…, then Insert

3D models

3D models

Drop a .glb, .gltf or .obj file on a slide to get an interactive 3D view. Models dropped together share one view. While presenting, drag to orbit and scroll to zoom.

Where: Drag a model onto the slide, then Props tab›Web page›Shading (auto, clay, normals, depth, uv, wireframe)

In HTML
data-element="web" data-fragment="shading=normals"

Web pages

Live web pages

A complete HTML page running live in a box on the slide: an interactive chart, a slider demo, a page someone already built. It runs sandboxed with no network. The editor shows a still of it until you interact with it.

Where: Added by an agent, then double-click it, or Props tab›Web page›Interact with page, and Page receives clicks while presenting

In HTML
<div data-element="web" data-src="assets/web/chart.a1b2c3d4.html"
     data-title="Training curves" style="width:1680px;height:780px"></div>

HTML regions

Markup the editor has no object for (a multi-part SVG, a clipped panel) is kept as one HTML region. You can move and resize it; its contents change only by rewriting the markup.

Where: On the slide, like any object

In HTML
<div data-element="html">…</div>

Presenting

Play the slideshow

Starts from the current slide. With several slides selected in the navigator, only those are shown. The audience view goes to a second display when there is one.

Where: Toolbar›Present

Presenter display

Your screen shows the current and next slide, elapsed and per-slide timers, the time and your notes, with Previous, Blank, Next, Switch displays and End show. It opens on its own when there are two displays.

Where: Toolbar›Present menu›Present in Speaker View

Keys while presenting

Next: Right, Down, Space, Page Down, Return or click. Previous: Left, Up, Page Up, Backspace or right-click. Home goes to the first slide, Esc ends the show. The pointer hides after a second without moving.

Where: In the presentation window

Black screen

Black out the audience screen and bring it back.

Where: While presenting, B, or the presenter display›Blank

Phone remote

In a collaboration session, hand the remote to someone in it, for example your own phone. Their screen shows the current and next slide, notes, timers and large Previous and Next buttons. Swiping works too.

Where: Presenter display›Remote…, or R, or the Remote… button in the presentation, then Give remote

Phone view

A session link opened on a phone gives a layout made for it: slides, notes and comments. On a phone you can edit presenter notes and comments and present, but not change slides.

Where: Open the invite link on a phone›Notes, Comments, All slides, Present, Agent

Collaboration

Collaborate

Starts a live session and copies an invite link. Anyone on the same local network or tailnet opens it in a browser, enters a name and edits with you. End collaboration saves and closes the session for everyone.

Where: Toolbar›Collaborate, then End collaboration

See who is editing

Everyone's slide, pointer and selection show as they work. Click a person's chip in the toolbar to go to where they are.

Where: Toolbar›a person's chip

Comments

Threads on a slide or an object, with replies, Resolve and a Link that opens the deck at the thread. Open threads show as an amber highlight in the editor, never when presenting.

Where: Right-click an object›Comment…, or right-click the slide background or a thumbnail›Comment on slide…

Chat

A chat for everyone in a browser session, kept apart from the deck. Type @ to mention someone, or @agent for the agent.

Where: Chat tab (browser editor)

Headless server

Keep a folder of decks available for editing in the browser without the desktop app running. Each subfolder with a deck shows up in the list. Run it only on a network you trust.

Where: npm run collab -- /path/to/decks in a DeckWerk checkout

Download a deck

Download the deck you are editing in the browser as a zip of its folder.

Where: Browser editor›File›Save and export›Deck archive (.zip)…

Working with agents

An agent (Claude Code, Codex or similar) edits the same deck you do. Its edits land as named steps in History, so you can undo them.

Agent… in the desktop app

Saves the deck and shows its folder path to copy. Start your agent in that folder: the AGENTS.md there tells it how to work on the deck.

Where: Toolbar›Agent…›Copy

Agent… in the browser

Copies a prompt. Paste it into your agent and it sets up a live folder copy of the deck by itself. The panel says Connected once it is in.

Where: Browser editor›Agent…›Copy prompt

How an agent edits

The agent exports slides as an HTML page, edits it, and saves it in the deck's edit/ folder. The editor picks up each save within a few seconds as one undoable change. New slides start from slide-agent new, which can only add.

Where: slide-agent context, slide-agent inspect --html --slide 4, slide-agent new

In HTML
slide-agent context
slide-agent inspect --html --slide 4 > edit/work.html

Render and check

An agent can render slides to PNG (with every animation finished, or as a contact sheet) and check for overflowing text, missing files and broken references.

Where: slide-agent render, slide-agent validate

Capabilities

Every feature on this page that an agent can author, with a working example. Agents read it before they write a slide.

Where: slide-agent capabilities

What to ask

Name slides by the number the navigator shows. Say what should change and what must stay. Ask for the deck's own style unless you want a new one, and ask the agent to render the slides it changed. For example: "Slide 12 is too dense: split it into two slides, keep the figure, move the details to the notes, and render both."

Where: Your agent's prompt

Import and export

Export to PDF

One page per slide, or one page per animation step.

Where: File›Save and export›Export PDF…›Include each stage of builds

Export for the web

A folder that plays the deck in any browser with the same player the app uses. Balanced and Compact cut each video to the part the slides play and re-encode it; Original copies media unchanged. Skipped slides are left out.

Where: File›Save and export›Export Web…›Media quality

Export images

Slides as PNG files. There is no menu item for it; an agent or the command line renders them.

Where: slide-agent render <deck> --slide 4 --output <folder>

Save As

A deck is a folder. Save As copies it to a new folder and switches to the copy. Edits save on their own; Cmd+S saves at once.

Where: File›Save and export›Save As…

Open Keynote and PowerPoint files

Open a .key, .pptx, .ppsx or .potx file as a new DeckWerk deck. Keynote does not need to be installed. Anything that cannot be converted becomes a placeholder.

Where: File›Import›Keynote… or PowerPoint…, or the welcome screen

Settings and appearance

Settings

Settings change the editor, not your slides, and apply at once.

Where: DeckWerk menu›Settings…, or Cmd+, (Ctrl+, on Windows and Linux)

Light and dark

The editor follows the system, or stays light or dark.

Where: Settings›Appearance›Theme›System, Light, Dark, or DeckWerk menu›Appearance

Interface font and size

The font of the editor's own controls (DeckWerk's Monaspace Krypton, the system font, or an installed font) and their size, from 85% to 130%. Slides keep their own fonts.

Where: Settings›Interface›Font, Scale

Keyboard shortcuts

Cmd+Z undo, Cmd+Shift+Z redo, Cmd+S save, Cmd+D duplicate, Cmd+A select all, N new slide, Cmd+R rulers, Escape deselect. On Windows and Linux use Ctrl.

Where: Anywhere in the editor
